# 자르기·배치 규칙

macOS 버전(`macos/Sources/MogoCore`)이 하는 일을 플랫폼과 상관없이 적은 문서다. Windows 버전 등 다른 구현은 이 규칙을 따르고,
시험지별 기준값 [`expected/samples.json`](expected/samples.json)과 같은 결과(여백 ±1.5mm, 배율 ±0.01)를 내야 한다.
쪽수, 형·선택과목 판정, 쓰는 쪽 번호는 정확히 같아야 한다.

여백 허용 오차가 50dpi 한 픽셀(0.5mm)보다 큰 이유: 평가원 시험지 아래쪽의 회색 저작권 문구("…한국교육과정평가원에 있습니다.")처럼
연한 작은 글자는 50dpi에서 밝기가 기준값 200 근처로 그려진다. 렌더러마다 글자 안티에일리어싱이 달라
(macOS CoreGraphics와 Windows PDFium) 끝 픽셀 1~3개가 잉크로 잡히기도 하고 안 잡히기도 한다.
2026년 11월 실측에서 23개 시험지의 최대 차이는 여백 1.4mm, 배율 0.0013이었다(인쇄 위치 차이 0.7mm 이하).

## 1. 파일 받기
- PDF 파일이나 폴더를 받는다. 폴더는 하위 폴더까지 펼친다.
- 확장자가 `pdf`(대소문자 무시)인 파일만, 이름이 `.`으로 시작하는 파일(macOS의 `._*` 등)은 뺀다.
- 폴더 안 순서는 폴더 기준 상대 경로의 **자연 정렬**(숫자는 크기 순: `2.pdf` < `10.pdf`).
- 한 번에 받은 묶음(여러 파일을 같이 끌어 놓은 경우)은 파일 이름 자연 정렬로 넣는다. 그 뒤 순서는 사용자가 바꾼다.
- 이미 목록에 있는 파일(심볼릭 링크를 풀어 같은 경로)은 다시 넣지 않는다.
- 암호가 걸렸거나 열 수 없는 PDF는 넣지 않고 알린다.

## 2. 페이지 좌표
- 페이지 크기는 **cropBox** 기준, **/Rotate를 반영한 화면 방향**으로 본다(90·270도면 가로세로가 바뀜).
- 좌표 원점은 왼쪽 아래, 단위는 pt(1mm = 72/25.4pt).

## 3. 홀수형·짝수형
1. 페이지 텍스트에서 공백·줄바꿈과 괄호류 `( ) （ ） [ ] ［ ］ 〔 〕 「 」 < > 〈 〉`를 지운다.
2. `홀수형`만 있으면 홀수형, `짝수형`만 있으면 짝수형, 둘 다 있거나 둘 다 없으면 라벨 없음.
   (정답표의 `( 홀수 )형` 표기도 이렇게 잡힌다.)
3. 라벨이 없는 페이지는 앞 페이지 라벨을 이어받는다. 첫 라벨이 나오기 전 페이지(표지 등)는 라벨 없음으로 남는다.
4. 한 파일에 홀수형과 짝수형이 **둘 다** 있을 때만 형 선택을 적용한다.
   고른 형의 페이지와 라벨 없는 페이지를 쓴다. "전체"면 모든 페이지. 한 형만 있는 파일은 언제나 전체.

## 3-1. 선택과목 (2022~2027학년도 국어·수학)
1. 페이지 텍스트에서 공백·줄바꿈을 지우고 전각 괄호 `（ ）`를 반각으로 바꾼다.
2. 안내문 `선택과목(…)`(예: "이어서, 「선택과목(화법과 작문)」 문제가 제시되오니")을 지운다.
   공통 과목 마지막 쪽과 선택과목 쪽 끝에 다음 과목 안내로 나오기 때문이다.
3. 남은 글에서 괄호로 싼 과목명을 찾는다: `(화법과작문)`, `(언어와매체)`, `(확률과통계)`, `(미적분)`, `(기하)`.
   정확히 하나만 나오면 그 선택과목 쪽, 없거나 둘 이상이면 공통 쪽으로 본다(앞 쪽 라벨을 이어받지 않는다).
4. 과목별(국어: 화작·언매, 수학: 확통·미적·기하)로 사용자가 하나를 고르면 그 과목 쪽과 공통 쪽만 쓴다.
   고르지 않으면 모든 쪽을 쓴다. 형 선택(3절)을 먼저 하고 그 결과에 선택과목을 적용한다.

## 4. 내용(잉크) 영역
- 페이지를 **50dpi 회색조**로, 흰 배경 위에 화면 방향대로 그린다.
- 밝기 값(0~255)이 **200 미만**인 픽셀들의 경계 사각형을 pt로 바꾼다. 그런 픽셀이 없으면 빈 페이지(영역 없음).

## 5. 자를 범위
파일마다, 고른 페이지들 가운데 **크기가 같은(1pt 단위 반올림) 페이지끼리** 한 범위를 쓴다(글자 크기가 쪽마다 같게).
1. 그 페이지들의 잉크 영역을 모두 합친다. 잉크가 하나도 없으면 페이지 전체.
2. 사방으로 **1.5mm** 넓힌다.
3. 사용자 손 조정(mm)을 적용한다. 위·아래·왼쪽·오른쪽 각각 +는 안쪽으로 더 자르고 −는 넓힌다.
   "자동 자르기 끄기"면 1~2단계 대신 페이지 전체에서 시작한다(넓히기 없음).
4. 페이지 범위와 겹치는 부분만 남긴다. 남은 폭이나 높이가 36pt(0.5인치) 미만이면 페이지 전체를 쓴다.

## 6. 배율과 배치
- 용지 A4 = 595.28 × 841.89pt. 종이 여백 기본 **5mm**(사용자가 3~15mm로 바꿈).
- 배율 = min((A4 폭 − 2×여백) / 자른 폭, (A4 높이 − 2×여백) / 자른 높이, **1.0**). 원본보다 키우지 않는다.
- 자른 영역을 배율대로 줄여 A4 **가로·세로 한가운데**에 놓고, 자른 영역 밖은 그리지 않는다.
- 원본을 이미지로 굽지 않고 벡터 그대로 그린다(글자가 선명하게).

## 7. 빈 쪽
- **양면** 인쇄일 때, 쪽수가 홀수인 파일 뒤에 빈 A4 한 쪽을 넣어 다음 파일이 새 종이 앞면에서 시작하게 한다.
  마지막 파일 뒤에는 넣지 않는다.
- 양면이면서 **2부 이상**이면 마지막 파일 뒤에도 넣어, 다음 부가 앞 부의 마지막 장 뒷면에서 시작하지 않게 한다.
- 단면이면 넣지 않는다.

## 8. 인쇄
- 기본값: A4, 양면 긴 쪽 넘김, 흑백, 1부. 여러 부면 한 부씩 순서대로(collate).
- 맥(CUPS) 표준 옵션: `media=A4`, `sides=two-sided-long-edge`(단면 `one-sided`), `print-color-mode=monochrome`(컬러 `color`).
  드라이버가 지원하면 `PageSize=A4`, `Duplex=DuplexNoTumble`(단면 `None`), `ColorModel=Gray` 계열(컬러는 `RGB` 계열)도 넣는다.
- 인쇄 전에 프린터·분량·설정·형·파일 목록을 보여 주고 확인받는다.
- 프린터의 A4 인쇄 불가 여백(네 변 중 가장 큰 값)이 종이 여백보다 크면 경고한다.

## 기준값 파일
`expected/samples.json`의 `files` 항목 하나는 위 규칙을 **파일 하나만, 기본 설정(A4·여백 5mm·홀수형·선택과목 전체)**으로 돌린 결과다.

| 키 | 뜻 |
|---|---|
| `path` | `Samples/` 기준 상대 경로(NFC 한글) |
| `pages` | 원본 쪽수 |
| `labels` | 쪽별 형 라벨(3단계까지): `O` 홀수형, `E` 짝수형, `-` 없음 |
| `elective_labels` | 쪽별 선택과목(3-1절): `S` 화법과 작문, `L` 언어와 매체, `P` 확률과 통계, `C` 미적분, `G` 기하, `-` 공통 |
| `both_variants` | 홀·짝 합본인지 |
| `odd_page_count`, `even_page_count` | 홀수형·짝수형을 골랐을 때 쓰는 쪽수 |
| `page_size_mm` | 첫 쪽 크기(화면 방향) |
| `crop_margin_mm` | 첫 쪽 기준 자른 범위 바깥 여백(왼·위·오른·아래) |
| `scale` | 원본 대비 배율 |

샘플 PDF 자체는 평가원 저작물이라 저장소에 없다. 평가원 수능 홈페이지 기출문제 게시판에서 받아 `Samples/`에 같은 경로로 두면 된다.
macOS 버전에서 기준값 다시 생성: `cd macos && MOGO_UPDATE_GOLDEN=1 swift test --filter GoldenTests`.

## 부록: 평가원에서 받기
- 게시판: 수능 `boardID=1500234`, 모의평가 `boardID=1500236`. 주소 `https://www.suneung.re.kr/boardCnts/list.do?boardID=…&m=0403&s=suneung`.
- 검색: 학년도 `C01=2026`, 모의평가는 월 `C02=6월|9월`. 이렇게 거르면 그 해 영역(국어·수학·영어·한국사·사회탐구·과학탐구·직업탐구·제2외국어/한문)이 한 쪽에 모두 나온다.
  고를 수 있는 학년도는 같은 쪽의 `<select name="C01">` 선택지에서 읽는다.
- 표: 머리줄 `<th>`에서 '학년도'·'월'·'영역' 열 위치를 찾는다(수능은 학년도·영역, 모의평가는 학년도·월·영역 순). 첨부는 `fn_fileDown('해시')`와 `title='파일 이름'`.
- 받기: `https://www.suneung.re.kr/boardCnts/fileDown.do?fileSeq=해시`. 쿠키·Referer 없이 받아진다. PDF는 `%PDF`, ZIP은 `PK`로 시작하는지 확인한다.
- 첨부 분류(이름 기준): '정답'이 들어가면 정답표, '듣기'·'음원'·'대본'이면 듣기 자료(받지 않음), 나머지는 문제지.
  학년도마다 이름이 다르다(2019 '국어영역.zip', 2015 '국어영역A형-홀수.pdf', 2022 '1교시_국어영역_문제지.zip').
- ZIP: 탐구는 과목별 PDF 묶음, 2022학년도 이전 문제지는 홀·짝 PDF 묶음이다. 파일 이름은 UTF-8 표시 없이 CP949로 들어 있다.
  안의 PDF만 꺼내고(`__MACOSX`, 숨김 파일 제외), 홀·짝이 따로 있으면 지금 고른 형만 기본 선택한다. 탐구는 응시 과목을 사용자가 고른다.
- 저장: `~/Downloads/모고 프린트/2026학년도 대학수학능력시험/2026수능_국어영역_문제지.pdf`, ZIP은 같은 이름의 폴더에 푼다. 이미 받은 파일은 다시 받지 않는다.
